8.1 원칙
  [R-8.1] 전역 지식 데이터는 존재하지 않는다.
          모든 NPC는 자기 관점으로 기록된 수첩 하나만 들고 있다.
  [R-8.2] 기억은 '대상별로 분리 저장'된다.
          A는 B에 대한 기억과 C에 대한 기억을 각각 따로 가진다.
  [R-8.3] B와 C의 '관계'는 A에게 직접 주어지지 않는다.
          A는 파편적 관찰을 조합해 스스로 추론(Inference)해야 한다.

8.2 기억 엔트리 구조

 <데이터 1> 기억 엔트리 예시 (JSON)

  [직접 목격]

8.3 관계 추론 (제3자 관계 인지)

  [R-8.4] NPC는 자신의 기억 조각을 집계해 '타인 간 관계 추정치'를 만든다.

      추정친밀도(B,C) = SUM( 관찰이벤트 가중치 x 신선도 )
        같은 장소 동석      +1
        선물/음식 제공      +4
        함께 이동           +3
        다툼/폭력          -6
        소문 청취          +해당 소문의 주장값 x confidence

  [R-8.5] 추정친밀도가 임계치를 넘으면 A의 머릿속에 '무리(Clique)' 라벨이 생긴다.
          예) 톰의 인식 : { "지미와 케이트" : 연인추정 0.7 }
                          { "밥, 한스, 올라프" : 패거리추정 0.8 }
  [R-8.6] 이 추정은 틀릴 수 있어야 한다. 실제 관계 데이터와 일치시키지 않는다.
          오해가 갈등을 낳고, 갈등이 이야기를 만든다.

 <그림 3> 관찰 -> 추론 -> 행동 흐름

    [관찰] 톰이 지미가 케이트에게 사과 주는 걸 목격
              |
    [소문] 밥이 "지미랑 케이트 요즘 붙어다니던데?" 라고 말함  (confidence 0.7)
              |
              v
    [추론] 톰의 장부 : 지미-케이트 친밀도 추정 0.72 -> '연인추정' 라벨 부여
              |
              v
    [행동] 톰이 케이트에게 구애 시도 -> 실패 확률 상향 보정,
           또는 톰이 지미에게 질투 Thought(-8) 획득 -> 관계 악화

8.4 망각
  [R-8.7] 기억은 NPC당 최대 60개. 초과 시 (중요도 x 신선도 x 감정무게)
          최하위부터 폐기한다. 단, importance >= 8 (사망/배신 등)은 폐기 대상 제외.
  [R-8.8] confidence < 0.15 로 떨어진 기억은 자동 폐기된다.
