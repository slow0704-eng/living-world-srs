9.1 획득 경로
 +-------------------------+------------------------------------------+------------------+
 | 경로                    | 조건                                     | 초기 확신도      |
 +-------------------------+------------------------------------------+------------------+
 | WITNESSED (직접 목격)   | 반경 N + 시야 확보 + 수면중 아님         | 0.9 ~ 1.0        |
 | HEARSAY   (대화 전파)   | 같은 노드에서 Socialize 행동 실행        | 전달자 x 0.6~0.9 |
 | EVIDENCE  (물증 발견)   | 시체, 빈 창고, 부서진 문                 | 0.5 (범인 불명)  |
 | OFFICIAL  (공식 발표)   | 게시판, 전령, 위병 보고                  | 0.85 (왜곡 없음) |
 | TOLD_BY_PLAYER          | 유저가 대화로 알려줌                     | 유저 신뢰도 비례 |
 +-------------------------+------------------------------------------+------------------+

9.2 전파 규칙

  [R-9.1] 저녁 시간대에 같은 노드(선술집/광장)에 모인 NPC들끼리 기억 리스트를
          비교하고, 아래 점수 상위 최대 2건을 교환한다.

      공유점수 = 중요도(1~10)
               x 신선도( 1 / (1 + 경과일수 * 0.3) )
               x 청자관련도( 청자의 마을/가족/직업/파벌이 얽히면 x2 )
               x 전달자 외향성( 0.5 ~ 1.5 )
               x 관계 신뢰( 0.5 ~ 1.2 )

  [R-9.2] 전파 시 열화
      confidence_new = confidence_old * (0.6 + 우호성 * 0.3)
      distortion_new = min(1.0, distortion_old + 0.15)
      distortion > 0.4 -> 필드 하나가 랜덤 왜곡
                          (인물 -> 인상착의 / 숫자 -> 과장 / 장소 -> 인근 지명)

  [R-9.3] 소문은 캐러밴/여행자/전령의 이동을 타고 마을 경계를 넘는다.
          지식의 텔레포트는 금지된다.

  [R-9.4] 유저 미접속 중에도 NPC 간 대화는 발생한다. 유저는 나중에 그 마을에서
          그동안 퍼진 소문을 들을 수 있어야 한다.

9.3 정보는 반드시 행동으로 연결된다
    - 위병이 MURDER(actor=player)를 confidence >= 0.6 획득 -> 수배 등록, 체포 시도
    - 상인이 BANDIT_ATTACK(북부도로) 획득 -> 우회, 호위 고용, 위험 프리미엄 반영
    - 농부가 HARVEST_FAILURE 획득 -> 가격 상승 예상 -> 판매 보류(투기)
    - 대장장이가 IRON_SHORTAGE 획득 -> 재고 확보 경쟁 -> 철 가격 추가 상승 (11장)
