6.1 3중 스태미너 구조 (핵심 설계)

  스태미너는 하나의 숫자가 아니라 '3개 층'으로 구성된다.

 <그림 2> 스태미너 3층 구조

    0                                                             100
    |---------------------------------------------------------------|
    |#############################|.................|xxxxxxxxxxxxxxx|
    |<-- 현재 지구력(current) --->|<- 회복 가능 여백 ->|<- 수면부족 손실 ->|
    |                             |                 |
    |                             |                 +-- absoluteMax (기본 최대치)
    |                             +-- recoveryCap (배고픔이 만든 회복 상한)
    |
    |                             ※ currentMax = absoluteMax - 수면부채
    |                                recoveryCap = currentMax x 허기계수

 <표 4> 3중 스태미너 정의
 +----------------+--------------------------+------------------------------------------+
 | 층             | 지배 요인                | 역할                                     |
 +----------------+--------------------------+------------------------------------------+
 | 절대 최대치    | 수면 부족(sleepDebt)     | 스태미너 바의 '천장' 자체를 깎는다       |
 |  currentMax    |                          | 회복해도 절대 여기 이상 못 올라감        |
 +----------------+--------------------------+------------------------------------------+
 | 회복 상한선    | 배고픔(satiety)          | 지금 회복할 수 있는 선을 제한한다        |
 |  recoveryCap   |                          | 배부르면 상한선이 최대치까지 열린다      |
 +----------------+--------------------------+------------------------------------------+
 | 실시간 지구력  | 행동(달리기/노동/전투)   | 지금 당장 쓰고 채우는 변동치             |
 |  current       |                          | 0이 되면 행동 불가, 강제 휴식            |
 +----------------+--------------------------+------------------------------------------+

  계산식
    sleepDebt   = clamp(누적 각성시간 - 기준각성시간, 0, absoluteMax * 0.6)
    currentMax  = absoluteMax - sleepDebt
    허기계수    = clamp(satiety / 60, 0.35, 1.0)
    recoveryCap = currentMax * 허기계수
    current     = clamp(current + 회복량 - 소모량, 0, recoveryCap)

  [R-6.1.1] 수면 부족은 currentMax를 최대 60%까지 깎을 수 있다.
            해소는 오직 수면으로만 가능하며, 수면 1시간당 부채 1.5시간 상환.
  [R-6.1.2] 배고픔은 current를 직접 깎지 않는다. '회복을 막을' 뿐이다.
            -> 굶주린 상태로 뛰면 지구력이 바닥나고 다시 안 찬다.
  [R-6.1.3] NPC도 동일 규칙을 따른다. currentMax가 40% 이하로 떨어진 노동자는
            Work 행동의 유틸리티 점수가 급락하여 스스로 조퇴/수면을 택한다.
            -> 이것이 11장 생산 차질의 근본 원인이 된다.

6.2 체력 (HP)
    - 부상, 굶주림(energy 0 지속), 질병, 전투로 감소
    - 자연 회복은 수면 + 포만 + 청결 조건을 만족할 때만 진행
    - 0 도달 시 사망. 사망은 되돌릴 수 없고 크로니클(14장)에 영구 기록된다.

6.3 욕구 (Needs)

 <표 5> 기본 욕구
 +------------------+-----------+-------+-------+----------------------------------+
 | 욕구             | 틱당 감소 | 경고  | 위험  | 미충족 시 효과                   |
 +------------------+-----------+-------+-------+----------------------------------+
 | 포만감 satiety   |   0.45    |  30   |  10   | 회복상한 하락, 위험 시 HP 감소   |
 | 수면   rest      |   0.35    |  30   |  10   | sleepDebt 누적 -> 최대치 하락    |
 | 사교   social    |   0.20    |  25   |   8   | 정신력 하락, 대화 욕구 상승      |
 | 안전   safety    | 상황반응  |  40   |  15   | 도주/신고 행동 트리거            |
 | 위생   hygiene   |   0.10    |  25   |   5   | 타인 호감도 감소, 질병 확률 상승 |
 | 여가   leisure   |   0.15    |  25   |  10   | 정신력 하락, 주점 방문 욕구      |
 +------------------+-----------+-------+-------+----------------------------------+

6.4 정신력 (Mind) — 림월드 + RDR2 방식

    정신력 = 기본치(50) + SUM(활성 Thought 값) + SUM(욕구 페널티) + 성격 보정

    * Thought는 만료 시간을 가진 임시 감정 기록이며 반드시 원인 이벤트 ID를 참조한다.
        예) 친구가 죽었다 : -20 / 15일
            맛있는 식사   :  +5 / 12시간
            유저가 선물   :  +8 / 3일
            비를 맞았다   :  -4 / 6시간
    * 구간별 행동
        0~15  정신 붕괴 (마을 이탈 / 폭력 / 폭음 / 파업)
       15~35  불안정 (실수 잦음, 파벌 선동에 취약)
       35~70  보통
       70~100 고양 (작업 효율 +15%, 타인에게 긍정 Thought 전파)

6.5 대인 심리 3축 (상대별로 개별 보유)

 +----------------+-------------+---------------------------------+---------------------+
 | 축             | 범위        | 상승 요인                       | 하락 요인           |
 +----------------+-------------+---------------------------------+---------------------+
 | 신뢰 trust     | -100 ~ 100  | 거래 성사, 약속 이행, 선물      | 배신, 절도 목격     |
 | 공포 fear      |    0 ~ 100  | 무기 겨눔, 유혈 목격, 악명      | 시간 경과, 우호 행동|
 | 분노 anger     |    0 ~ 100  | 소유물 침해, 모욕, 지인 피해    | 사과, 배상          |
 +----------------+-------------+---------------------------------+---------------------+

  [R-6.5.1] 유저가 무기를 뽑으면 1틱 이내에 반경 내 NPC의 fear +30 및
            행동 재평가가 강제 트리거된다. 다음 스케줄까지 기다리면 안 된다.
  [R-6.5.2] fear > 70 -> 도주 / anger > 70 & 전력 우위 -> 공격
            / fear 높고 위병 근처 -> 신고 (9장 정보 전파로 연결)
