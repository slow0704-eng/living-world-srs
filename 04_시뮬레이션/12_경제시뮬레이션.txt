11.1 원칙
  [R-11.1] 상품은 순간이동하지 않는다. 특정 위치의 재고로 존재하며,
           옮기려면 운반 주체(캐러밴/NPC/유저)가 물리적으로 이동해야 한다.
  [R-11.2] 원칙 P8에 따라 모든 물자는 산출 -> 가공 -> 소비/소멸 경로를 가진다.
           골드는 세금/징수/발행으로만 생성되며 무한 생성 금지.

11.2 생산 체인

    밀밭   --(밀)-->    방앗간 --(밀가루)--> 제빵소 --(빵)--> [전 인구 포만감]
    철광산 --(철광석)--> 제련소 --(철괴)---> 대장간 --+--(농기구)--> 농장 생산성
                                                      +--(무기)----> 위병 치안
                                                      +--(못/경첩)-> 건축/수리
    숲     --(원목)-->  제재소 --(목재)----> 건축 / 연료
    약초밭 --(약초)-->  조제소 --(포션)----> 치료

  [R-11.3] 각 시설은 노동자가 실제로 출근해 Work를 수행해야만 생산한다.
           노동자의 currentMax가 낮으면 생산량이 비례 감소한다. (6.1과 연결)

11.3 가격 형성
    가격 = 기준가 x 재고계수 x 수요계수 x 위험프리미엄 x 상인마진(탐욕도)
    재고계수 = clamp( (목표재고 / max(현재재고,1)) ^ 0.6 , 0.4 , 6.0 )

  [R-11.4] 가격은 정착지별로 독립적이다. 전역 통일 가격표 금지.
  [R-11.5] 유저의 대량 매입/매도는 해당 정착지 가격에 즉시 반영된다.
  [R-11.6] 상인 NPC는 '자신이 아는 가격 정보(기억)'로만 의사결정한다.
           틀린 정보로 손해를 보는 것이 허용되어야 한다.

11.4 캐러밴 에이전트 (켄시 / X4 방식)
  [R-11.7] 캐러밴 = 상인 1 + 호위 N. 맵 위를 실제로 걸어다니며 아래 루프를 돈다.
      1. 아는 가격 정보로 기대수익 계산
         기대수익 = (목적지 예상판매가 - 현지매입가) x 적재량 - 이동비 - 위험비
      2. 최고 수익 경로 선택 (위험 기억이 있으면 회피)
      3. 도로 노드를 따라 실시간 이동
      4. 이동 중 도적 조우 가능 -> 전투 / 약탈 / 도주
      5. 도착 -> 판매 -> 재고/가격 갱신 -> 소문 전달 (R-9.3)

11.5 자원 고갈 시나리오 지원 ('철 매점' 요구사항)

  [R-11.8] 특정 품목의 전량 매입 및 폐기(바다에 버리기)가 시스템적으로 허용된다.
  [R-11.9] 아래 연쇄가 스크립트 없이 자동 발생해야 한다.

      철 매점/폐기
        -> 대장간 철괴 재고 0
        -> (a) 농기구 생산 중단 -> 농기구 마모/파손 -> 농장 생산성 30% 하락
                                                    -> 식량 부족 -> 아사/이주
        -> (b) 무기 생산 중단 -> 위병 장비 노후 -> 치안 하락 -> 도적 활동 증가
                                                -> 캐러밴 피습 -> 교역 마비
        -> (c) 못/경첩 부족 -> 건물 수리 중단 -> 건물 붕괴 -> 노숙 -> 정신력 붕괴
        -> (d) 철 가격 폭등 -> 폐광 재개발 시도 / 원거리 수입 캐러밴 발생
                             / 인접 세력의 자원 침공 명분 발생 (13장)

  [R-11.10] 위 (d)처럼 '고갈에 대한 세계의 반작용'이 반드시 있어야 한다.
            반작용 없이 붕괴만 하면 시뮬레이션이 아니라 고장이다.
  [R-11.11] 광산 산출량은 유한하며 매장량 데이터를 가진다.
            매장량 고갈 시 해당 광산은 폐광되고 NPC들은 실직 -> 이주/전직한다.
