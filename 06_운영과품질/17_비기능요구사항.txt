 판타지 웹 RPG - 살아있는 세계(Living World) SRS v0.2
 [16] 비기능 요구사항
 관련 : [2] 원칙 P4 관측 가능성 / [3] 아키텍처 / [7] 접근성(R-7.1.2)

  기술스택(권장) : 서버 Node.js(TypeScript) / 상태 Redis / 영속 PostgreSQL
                   클라 React / 통신 WebSocket
  저장           : 5분마다 스냅샷. 거래/사망/크로니클은 영구 기록
  보안           : 모든 상태 변경은 서버 검증. 클라 입력은 '의도(intent)'로만 취급
  관측성         : 개체별 타임라인 뷰어 / 소문 확산 지도 / 품목별 가격 그래프
                   / 개체군 그래프 / 파벌 그래프 (개발자 대시보드 필수)
  확장성         : 정착지 단위 샤딩이 가능하도록 모듈 간 의존성 최소화
  접근성         : 색상 단독 정보 전달 금지(R-7.1.2), 스크린리더 대응
                   (텍스트 기반이므로 접근성은 오히려 강점)
