 node ../32_사바나XL_생태시뮬_검증.mjs --run --years 300
 node ../32_사바나XL_생태시뮬_검증.mjs --run --years 500 --seed 777 --tier L --climate TEMPERATE

 실행마다 두 파일이 남는다.
   *.txt   사람이 읽는 요약 — 설정 / 종 구성 / 연도별 표 / 자동 판독 / 사건 기록
   *.json  전체 시계열 + 종 이력 + 크로니클 + 그때의 TUNE 스냅샷

 [자동 판독]이 궤적에서 눈에 띄는 것을 먼저 뽑아 둔다.
   · 후반 평형값과 진폭, 유도 부양력 대비 비율
   · 절멸한 종과 연차
   · 목본 임관이 20%p 이상 오르면 관목림 천이로 표시
   · 화재가 절반 이하로 줄면 화재 체제 붕괴로 표시
   · 최상위 포식자 상실 전후의 초식 개체수 변화

 TUNE 스냅샷이 json에 함께 들어가므로,
 "그때 무슨 값으로 돌렸더라"를 나중에 되짚을 수 있다.
