 냉대는 이 설계에서 제외한다. 결빙 · 적설 · 동면은 별도의 상태 축을

 세 기후대는 전부 동일한 계산식을 쓰고 상수만 다르다.

 [원칙] 기후대는 '분위기'가 아니라 상수 묶음이다.
        열대 · 온대 · 사바나의 차이는 아래 <표 C-1> 한 장이 전부이며,
        나머지 모든 차이(사냥감 밀도 · 대이동 · 겨울 아사)는
        그 상수에서 유도되어야 한다.

[C-1] 기후 상수표 - 이 문서의 전부
--------------------------------------------------------------------------------

 <표 C-1> 기후대 상수 확정표
 +---------------------------+----------+----------+----------+
 | 상수                      | 열대     | 온대     | 사바나   |
 +---------------------------+----------+----------+----------+
 | [기온]
 | 연평균 기온        'C     |   26     |   12     |   24     |
 | 연교차 (최난-최한) 'C     |    3     |   24     |    6     |

 [C-1.1] 이 표 바깥에 기후대별 분기문(if climate == TROPICAL)을 두는 것을
         금지한다. 새 기후대를 추가할 때 이 표에 행 하나만 더하면
         작동해야 한다.

 [C-1.2] 세 기후를 가르는 진짜 축은 '덥다/춥다'가 아니라
         언제 성장이 멈추는가 이다.
           열대   : 멈추지 않는다        -> 비축이 필요 없다
           온대   : 겨울 4개월 멈춘다    -> 저장이 생존의 핵심
           사바나 : 건기 6개월 멈춘다    -> 이동이 생존의 핵심
         같은 '성장 정지'인데 대응 전략이 정반대인 것이
         이 세 기후를 함께 넣는 이유다.


--------------------------------------------------------------------------------
[C-2] 열대 (Tropical) - 풍요롭지만 비어 있는 숲
--------------------------------------------------------------------------------

 [C-2.1] 성격
   1차생산량은 세 기후 중 압도적 1위(2,200)인데 대형 초식 밀도는 꼴찌
   (10.0 마리/km2)다. 생산량 대부분이 수관층의 목질 · 난소화성 잎에 묶여
   있어 초식 가용률이 5%밖에 되지 않기 때문이다.
   -> 유저 체감 : "숲은 빽빽한데 사냥할 게 없다."
   이 역전은 <표 C-1>의 alpha 값에서 자동으로 나온다. 별도 규칙이 아니다.

 [C-2.2] 수직 층 구조
   열대만 식생을 3층으로 나눈다. 초식 접근 가능 여부가 층마다 다르다.
     · 수관층 (25 m~)  현존량의 70%. 지상 초식 접근 불가.
                       T2 수상성(원숭이 · 과일박쥐급)만 이용 가능.
     · 아교목 (5~25 m) 현존량의 20%. 대형 초식이 목을 뻗어 일부 이용.
     · 하층   (~5 m)   현존량의 10%. 지상 초식이 실제로 먹는 층.
   [C-2.3] alpha 0.05는 이 층 구조의 요약값이다. 층을 개별 시뮬할 여력이
           없는 LOD 등급에서는 alpha 하나로 대체한다.

 [C-2.4] 시그니처 사건
   · 폭우와 침식     : 표토가 15 cm뿐이라 벌목 · 화전 후 표토가 씻겨 내려간다.
                       지력 소모 배율 2.5 -> 화전은 2~3년이면 못 쓰게 된다.
   · 열대성 폭풍     : 우기 말 강풍. 수관층 파괴 -> 임상에 빛이 들어옴
                       -> 하층 식생 일시 폭증 -> 초식 일시 증가 -> 다시 폐쇄.
                       재난이 오히려 사냥감을 늘리는 유일한 기후다.
   · 부패와 질병     : 고온다습. 저장 식량 부패 속도가 온대의 3배.
                       -> 비축 전략 자체가 성립하지 않는다.

 [C-2.5] 은신처(Refugia)
   하천변 상록림, 산지 운무림(고도 800 m 이상 상시 결로대).
   열대는 원래 건기가 짧아 은신처 의존도가 낮지만, 대신 <표 I-5>대로
   종 수가 가장 많아 종당 개체수가 희소하다. 한 번 잃은 종은 돌아오지 않는다.

 [C-2.6] 인간에게 주는 압력
   식량은 흔하고 저장은 불가능하다 -> 잉여 축적이 어렵다
   -> 계층 분화와 교역이 늦게 발생한다. 대신 화전으로 인한 지력 붕괴가
      가장 빠르게 온다. 이동식 경작을 강제당한다.


--------------------------------------------------------------------------------
[C-3] 온대 (Temperate) - 저장하는 자만 겨울을 넘긴다
--------------------------------------------------------------------------------

 [C-3.1] 성격
   생산량은 중간(1,200)인데 초식 가용률이 20%로 열대의 4배다.
   낙엽활엽수의 잎 · 하층 관목 · 초지가 실제로 먹을 수 있는 형태다.
   결과적으로 대형 초식 밀도 21.9 마리/km2, 생물량으로는 열대의 3.3배다.

 [C-3.2] 계절 엔진
   연교차 24 'C는 세 기후 중 압도적 1위다. 25_기온엔진 [T-1]의
   Season_Multiplier 진폭이 가장 큰 기후이며, 여기서 4계절이 나온다.
     봄 (3개월) : 지력 회복, 식생 성장 재개, 번식 창
     여름(3개월) : 최대 생산. 잉여 발생.
     가을(3개월) : 성장 둔화. 저장 · 도축 · 수확.
     겨울(3개월) : 성장 정지(r = 0). 현존 식생만 소모된다.

 [C-3.3] 겨울 아사 판정 - 온대의 핵심 루프
   겨울 4개월 동안 식생 회복률이 0이므로 초식은 가을 현존량을 갉아먹는다.
     필요량 = 개체수 x intake x (정지기간 / 365)
     생존 조건 = 가을 현존량 x 접근가능률 >= 필요량
   이 부등식이 깨지면 겨울 아사가 발생한다. 확률 판정이 아니라 뺄셈이다.
   [C-3.4] 아사는 개체수 상위(성체 대형)부터가 아니라
           에너지 잔량 하위(유체 · 노령)부터 발생한다.
           (R-12.2 에너지 0 사망 규칙을 그대로 따르면 저절로 그렇게 된다)

 [C-3.5] 시그니처 사건
   · 혹한 (Cold Wave) : 25_기온엔진 [T-4] 이류 계산으로 북쪽 찬 공기가
                        내려오면 발생. 겨울 필요량이 증가해 아사선을 앞당긴다.
   · 늦서리          : 봄 성장 재개 직후의 저온. 신엽이 죽어 그 해 NPP가
                       20~40% 깎인다. 그 여파는 겨울에 아사로 청구된다.
                       (원인과 결과 사이 6개월 - 인과 추적의 좋은 예)
   · 풍년/흉년       : 강수 편차가 그대로 다음 겨울 생존 인구를 결정한다.

 [C-3.6] 은신처
   남향 저지 계곡(적설 · 저온 완충), 상록 침엽 패치(겨울에도 먹을 것이 있음).
   [W-4.4]대로 손배치가 아니라 고도 · 사면 방위 · 강수 계산의 결과여야 한다.

 [C-3.7] 인간에게 주는 압력
   저장이 가능하고(저온 · 저습) 저장이 필수다 -> 잉여 · 창고 · 소유 · 분배가
   자연스럽게 발생한다. 세 기후 중 사회 복잡도가 가장 빨리 오르는 무대다.
   반대로 겨울 재고 계산을 틀리면 인구가 한 번에 깎인다.


--------------------------------------------------------------------------------
[C-4] 사바나 (Savanna) - 사냥감은 많고, 물은 없다
--------------------------------------------------------------------------------

 [C-4.1] 성격
   생산량은 꼴찌(800)인데 초식 가용률이 45%로 압도적이다.
   풀은 거의 전부가 먹을 수 있는 형태이고, 식생 회복률 r도 1.8로 가장 높다
   (뜯겨도 빨리 자란다). 결과적으로 대형 초식 밀도 30.8 마리/km2이고
   개체가 크므로(평균 80 kg) 생물량은 2,466 kg/km2 - 열대의 6배다.
   세 기후 중 사냥감이 가장 많고 가장 크다.
   현존 식생량은 40 t/ha로 열대의 1/10 - 풍경은 휑한데 짐승은 가장 많다.

 [C-4.2] 건기/우기 이중 상태
   사바나만 셀 상태에 '수원 접근성(waterAccess)'을 추가로 둔다.
   최장 무강수 180일 동안 대부분의 셀은 물이 마르고, 영구 수원 셀만 남는다.

     우기 (6개월) : 물이 어디에나 있다 -> 초식이 섬 전역에 분산
                    -> 포식 성공률 하락 -> 초식 번식 창
     건기 (6개월) : 물이 영구 수원에만 있다 -> 초식이 수원 반경으로 집결
                    -> 국소 밀도 10~30배 -> 주변 식생 초토화
                    -> 포식 성공률 급등 -> 질병 전파율 급등

 [C-4.3] 대이동(Migration) - 사바나의 핵심 루프
   R-12.4의 '먹이 밀도 하락 -> 대이동'을 확률 이벤트로 만들지 않는다.
     이동 결정 = Utility AI (11_행동결정엔진)의 일반 규칙으로 처리
       갈증 효용 = f(수분 잔량) x 1/거리(가장 가까운 수원)
       섭식 효용 = f(에너지) x 국소 식생량
     건기가 진행되면 갈증 효용이 섭식 효용을 압도하고,
     결과적으로 개체들이 수원으로 몰린다. 이것이 대이동이다.
   [C-4.4] 즉 대이동은 이동 로직이 아니라 두 효용의 교차점이다.
           별도의 마이그레이션 시스템을 만들지 않는다. (원칙 P6)

 [C-4.5] 화재 - 사바나에만 있는 제3의 조절 장치
   포식자만으로는 조절이 부족한 대신 화재가 그 역할을 한다.
     발화 조건 = 건조도 x 현존 식생량 x 발화원(낙뢰 또는 인간)
     결과      = 해당 셀 현존 식생 소각 -> 재로 지력 +
                 -> 우기에 신초 폭발적 재생(r=1.8) -> 초식이 몰림
   [C-4.6] 화재는 파괴가 아니라 사바나 생태계의 정상 작동이다.
           인간이 화재를 완전히 막으면 목본이 침입해 초지가 관목림으로
           천이하고, 초식 가용률 alpha가 떨어져 사냥감이 줄어든다.
           -> "불을 끄면 사냥감이 사라진다"는 반직관적 인과가 저절로 나온다.

 [C-4.7] 은신처
   영구 수원(용천 · 호수), 하안림(강가 회랑림). 이 셀들이 건기 6개월 동안
   섬 전체 생물량의 씨앗을 보관한다.
   [C-4.8] 사바나에서 은신처를 잃는 것은 다른 기후와 무게가 다르다.
           수원 하나가 마르면 그 반경의 개체군이 통째로 소멸한다.
           인간이 상류를 막거나 수원을 독점하면 이것이 즉시 발생한다.
           -> 27_5층_인간_개입지점과 가장 강하게 연결되는 기후.

 [C-4.9] 인간에게 주는 압력
   사냥은 쉽고 농사는 어렵다(1기작, 지력 회복 배율 0.6).
   저수 용량 확보가 인구 상한을 결정한다([I-8.3] 인구 100명당 약 9,900 m3).
   -> 목축 · 이동 · 수원 통제가 사회 구조의 중심이 된다.


--------------------------------------------------------------------------------
[C-5] 종 구성 규칙 - 종 목록을 손으로 쓰지 않는다
--------------------------------------------------------------------------------

 [C-5.1] 종은 아래 6개 필드만 갖는다. 이름은 표시용이며 로직에 쓰이지 않는다.
           trophic(T0~TF) / 체중(kg) / 식이폭(먹이 후보 수) /
           번식률 / 이동속도 / 내건성(0~1)

 [C-5.2] 대체재 요구 (26_4층_생명 [W-4.1])
         모든 초식종의 식이폭 >= 2, 모든 육식종의 식이폭 >= 2 를 강제한다.
         생성된 종 목록이 이를 만족하지 못하면 종을 추가하거나 리롤한다.
         식이폭 1인 종이 하나라도 있으면 그 종은 첫 재난에 소멸한다.

 [C-5.3] 기후대별 종 편성 비율 (<표 I-5>의 종 수를 이 비율로 배분)
 +----------+-----+-----+-----+-----+-----+-----+
 | 기후     | T0  | T1  | T2  | T3  | T4  | T5  |
 +----------+-----+-----+-----+-----+-----+-----+
 | 열대     | 45% | 20% | 20% |  8% |  5% |  2% |
 | 온대     | 40% | 15% | 22% | 13% |  7% |  3% |
 | 사바나   | 30% | 15% | 25% | 20% |  7% |  3% |
 +----------+-----+-----+-----+-----+-----+-----+
   ※ 배분 결과 개체수가 [I-6.1]의 50 미만이면 그 종은 결번 처리한다.
      비율은 '희망'이고 면적이 '판정'이다.

 [C-5.4] 기후대별 내건성 하한
           열대 0.1 / 온대 0.3 / 사바나 0.7
         사바나에 내건성 0.2짜리 종을 넣으면 첫 건기에 전멸한다.
         이는 버그가 아니라 [C-1]의 결과이므로 생성 단계에서 걸러야 한다.

 [C-5.5] 체중 분포는 기후대별로 다르다.
           열대   : 소형 편중 (섬 왜소화 + 수관층 의존)
                    T3 평균 체중을 기본값 60 kg -> 40 kg로 하향
           온대   : 기본값 그대로
           사바나 : 대형 편중. T3 평균 80 kg
         [C-5.6] S 티어(10 km2)에서는 기후 무관하게 T3 평균 체중에
                 왜소화 계수 0.6을 곱한다. [I-6.1] 준자립 페널티의 구체 형태다.


--------------------------------------------------------------------------------
[C-6] 세 기후가 같은 사건에 다르게 반응하는가 (검증용 대조표)
--------------------------------------------------------------------------------

 아래 표는 '같은 입력, 다른 결과'가 상수만으로 나오는지 확인하는 용도다.
 코드에 기후별 분기가 하나라도 있으면 이 표는 의미를 잃는다.

 <표 C-2> 동일 사건에 대한 기후대별 반응
 +----------------+-------------------+-------------------+------------------+
 | 사건           | 열대              | 온대              | 사바나           |
 +----------------+-------------------+-------------------+------------------+
 | 유저가 대형    | 원래 육식이       | 초식 폭증 ->      | 초식 폭증 ->     |
 | 육식을 전멸    | 결번(XL만 존재).  | 겨울 대량 아사    | 건기 수원 집결   |
 |                | 변화 미미         | -> 진동 후 회복   | -> 초토화 -> 화재|
 |                |                   |                   | -> 급격 회복     |
 +----------------+-------------------+-------------------+------------------+
 | 대규모 벌목    | 표토 유실 ->      | 지력 서서히 감소  | 목본 제거 ->     |
 |                | 지력 붕괴(2~3년)  | (10년 단위)       | 초지 확대 ->     |
 |                | 회복 거의 불가    | 회복 가능         | 사냥감 오히려 증가|
 +----------------+-------------------+-------------------+------------------+
 | 1년 강수 -40%  | 영향 경미         | 그 해 흉년 ->     | 건기 240일 ->    |
 |                | (연 2,500mm 여유) | 다음 겨울 아사    | 수원 고갈 ->     |
 |                |                   |                   | 개체군 절반 소멸 |
 +----------------+-------------------+-------------------+------------------+
 | 인간이 화재를  | 해당 없음         | 산불 감소,        | 목본 침입 ->     |
 | 전면 진압      | (습해서 안 탐)    | 큰 영향 없음      | alpha 하락 ->    |
 |                |                   |                   | 사냥감 장기 감소 |
 +----------------+-------------------+-------------------+------------------+
 | 식량 비축 시도 | 부패로 실패       | 성공 -> 잉여 ->   | 부분 성공        |
 |                | -> 잉여 축적 불가 | 계층 분화         | (건조 저장)      |
 +----------------+-------------------+-------------------+------------------+

 [C-6.1] 위 표의 모든 칸은 예측이지 명세가 아니다.
         구현 후 시뮬레이션이 이 표와 다르게 움직이면,
         코드가 아니라 <표 C-1> 상수를 먼저 의심한다.
         그래도 안 맞으면 이 표를 고친다. 코드에 예외를 넣지 않는다.
