 관련 : 23_2층_엔진(광량) / 24_3층_순환(바람) / 06_운영과품질\16_성능_LOD.txt

 기온(Temperature)은 "오늘 날씨는 몇 도"라고 고정하는 값이 아니라,
 에너지의 유입과 방출이 실시간으로 더하기 빼기 되는 밸런스 방정식이다.
 복잡한 열역학 대신 아래 4단계면 충분하다.


--------------------------------------------------------------------------------
[T-1] 기본 원천 : 태양 에너지 (Inflow)
--------------------------------------------------------------------------------
   계산식 : Solar_Heat = Sky_Dome_Intensity * Latitude_Factor * Season_Multiplier
   의미   : 스카이돔에서 쏟아지는 광량이 많을수록, 그리고 태양이 수직으로
            내리쬐는 위치에 가까울수록 해당 그리드의 기본 열에너지가 높아진다.

--------------------------------------------------------------------------------
[T-2] 지형과 대지의 성질 (Thermal Mass / Albedo)
--------------------------------------------------------------------------------
   똑같은 햇빛을 받아도 모래 · 물 · 숲은 온도가 오르는 속도가 다르다.
   이를 열용량과 반사율(Albedo)로 단순 구현한다.

     · 물   : 열용량이 매우 커서 천천히 데워지고 천천히 식는다 (해양성 기후)
     · 사막/바위 : 열용량이 낮아 순식간에 뜨거워지고 순식간에 식는다
                   (대륙성 · 사막 기후)
     · 숲   : 그늘과 증산 작용으로 급격한 상승을 막는 완충 역할(Buffer)

   ※ 숲의 완충 효과가 있어야 3층의 "벌목 -> 사막화" 연쇄가 성립한다.

--------------------------------------------------------------------------------
[T-3] 고도에 따른 냉각 (Altitude Lapse Rate)
--------------------------------------------------------------------------------
   계산식 : Altitude_Penalty = Tile_Elevation * Cooling_Rate
   의미   : 지형이 높을수록 기본 기온에서 강제로 마이너스한다.
            이 규칙 하나로 "적도 부근 높은 산맥 꼭대기의 만년설"이
            별도 코딩 없이 저절로 구현된다.

--------------------------------------------------------------------------------
[T-4] 바람과 해류에 의한 열의 이동 (Advection)
--------------------------------------------------------------------------------
   계산식 : Current_Temp = (My_Temp + Neighbor_Temp) / 2
            (바람이 불어오는 방향의 공기 온도를 일정 비율로 섞는다)
   의미   : 북쪽의 찬 바람이 남하하면 남쪽 기온이 뚝 떨어지는
            '한파(Cold Wave)'가 자연스럽게 연출된다.


--------------------------------------------------------------------------------
[T-5] 최종 루프 요약
--------------------------------------------------------------------------------

  매 게임 틱마다 각 그리드는 아래 연산을 한 번에 처리한다.

   [기본 기온] = [태양열 에너지]
               - [고도에 따른 냉각]
               + [주변 바람이 실어 나른 열]
               ± [지형의 특성 (물 / 숲의 보정값)]


--------------------------------------------------------------------------------
[T-6] 연산량 분석 : 왜 성능 부담이 거의 없는가
--------------------------------------------------------------------------------

  · 그리드 스케일 : 100km x 100km 세계를 1km x 1km 격자로 쪼개면
                    대륙 전체는 고작 10,000칸(Tile)이다.
  · 연산 성격     : 1만 칸에 대해 매 틱 [태양열 + 고도보정 + 인접 칸 평균] 같은
                    단순 사칙연산만 수행한다.
  · CPU 여력      : 현대 CPU는 초당 수십억 연산을 한다. 1만 칸의 사칙연산은
                    1밀리초도 걸리지 않으며 프레임 드랍을 유발하지 않는다.

 [W-3.6] 단, 격자 해상도를 1km보다 잘게 쪼개면 연산량은 제곱으로 늘어난다.
         100m 격자 = 1,000,000칸 = 100배. 해상도 결정은
         28_미확정항목_체크리스트.txt 5번 항목으로 보류 중이다.
         -> 06_운영과품질\16_성능_LOD.txt의 LOD 등급을 환경 그리드에도
            적용할지 여부를 함께 결정할 것.
