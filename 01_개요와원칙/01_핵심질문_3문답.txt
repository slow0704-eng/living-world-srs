Q1. NPC가 세계를 인식하고, 유저 없이도 대화로 정보를 공유할 수 있는가?
A1. 가능하다. 단, 전역 플래그가 아니라 '개인별 기억 장부' 방식이어야 한다.
       (X) world.ironIsGone = true      <- 지구 반대편 NPC도 즉시 안다
       (O) 사건 발생 -> 목격자만 기억 획득 -> 대화/캐러밴을 타고 물리적으로 전파
    정보는 상품과 똑같다. 순간이동하지 않는다.

Q2. 서사(스토리)부터 만들어야 하나, 생태계(관목->초식->육식)부터 만들어야 하나?
A2. 둘 다 아니다. '통합 엔티티 스키마'부터다. (5장)
    - 서사부터 가면 : 시뮬레이션이 서사의 장식품이 되어, 결국 스크립트 게임이 된다.
    - 생태계부터 가면 : 재미없는 엑셀 시트가 완성되고 동기 부여가 끊긴다.
    - 정답 : 모든 생물(인간/늑대/토끼/관목)이 공유하는 최소 공통 속성
             {위치, 에너지(배고픔), 체력, 공포, 기억, 포식태그} 를 먼저 정의한다.
             그러면 늑대 AI를 만드는 코드가 그대로 인간 AI의 뼈대가 된다.
             생태계는 '인간 시뮬레이션의 축소판'이지 별개 시스템이 아니다.
    구현 순서 : 공통 스키마 -> 식물/초식/육식(검증용 소규모 생태계)
                -> 인간(직업/경제) -> 기억/소문 -> 파벌 -> 서사(동적 사건)

Q3. "세계의 철을 모조리 사들여 바다에 버리면 문명이 어떻게 되는가"를 구현할 수 있나?
A3. 가능하다. 단 아래 3가지가 전제되어야 한다. (11장)
    (1) 철은 유한하며 생성 경로(광산 산출량)가 명시적으로 정의될 것
    (2) 철을 소비하는 하위 체인(농기구->수확량, 무기->치안, 못->건축)이 실재할 것
    (3) 상품 소멸(바다에 버리기)이 시스템적으로 허용될 것
    이 3개가 있으면 문명 붕괴는 '기획'하지 않아도 저절로 일어난다.
