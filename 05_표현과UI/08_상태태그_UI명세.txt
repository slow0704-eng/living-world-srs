7.1 이름표 상태 태그

  텍스트 기반의 최대 약점은 "화면에 [톰]이라고만 떠서 상태를 알 수 없다"는 것이다.
  이를 이름 옆 실시간 태그로 해결한다.

 <표 6> 상태 태그 카테고리
 +----------+---------------------------------------------+--------------------------------+
 | 분류     | 태그 예시                                   | 유저가 읽어내는 정보           |
 +----------+---------------------------------------------+--------------------------------+
 | 생리     | 졸림, 배고픔, 지침, 부상, 병듦, 취함        | 수면부채로 최대치가 깎였구나   |
 | 정서     | 신남, 슬픔, 분노, 두려움, 외로움, 평온      | 정신력이 위험하겠구나          |
 | 의복/외형| 화려함, 남루함, 젖음, 무장, 피투성이        | 파티 참석? 비? 방금 싸웠나?    |
 | 사회     | 수배중, 신참, 유명인, 빚쟁이                | 접근 시 주의가 필요하겠군      |
 +----------+---------------------------------------------+--------------------------------+

  [R-7.1.1] 태그는 최대 2개까지만 노출한다.
            노출 우선순위 = 지배도 점수 = (정규화된 강도) x (분류 가중치)
            생리 1.2 > 사회 1.1 > 정서 1.0 > 의복 0.8
  [R-7.1.2] 태그에는 색상 마커를 병기한다. (색맹 대응으로 색상 단독 사용 금지)
            녹색=양호 / 노랑=주의 / 주황=경고 / 적색=위험 / 파랑=환경(젖음,추위)
  [R-7.1.3] 태그 클릭(또는 hover) 시 원인 문장을 노출한다.
            예) [졸림] -> "32시간째 깨어 있음. 최대 스태미너 -38"
                이것이 원칙 P7 '인과 가시성'의 최소 구현이다.
  [R-7.1.4] NPC와 유저 모두 동일한 태그 규칙을 적용한다.

7.2 통합 스태미너 바 UI

  하나의 바 안에 3개 층을 시각적으로 겹쳐 표현한다.

    [■■■■■■■■■■■■■■■■□□□□□▓▓▓▓▓▓▓]
     ^-- 현재 지구력   ^        ^
                       |        +-- 수면부족으로 잠긴 구간 (빗금/어둡게)
                       +-- 배고픔으로 회복 불가한 구간 (반투명)

  [R-7.2.1] 잠긴 구간에는 마우스 오버 시 원인 툴팁을 반드시 제공한다.
  [R-7.2.2] 최대치가 감소하는 순간 짧은 토스트를 띄운다.
            "수면 부족 — 최대 스태미너가 줄어들고 있습니다"
  [R-7.2.3] 정보를 감추어 얻는 '핍진성'보다 원인을 알려주는 '납득'을 우선한다.
            불친절함은 리얼리즘이 아니라 그냥 불쾌함이다.
